# Biblioteca de SOPs detalhados para Docmost

Este pacote contém 10 SOPs empresariais detalhados e 1 template universal.

Todos os SOPs incluem:

- fluxo Mermaid;
- objetivo e escopo;
- entradas e saídas;
- matriz RACI;
- procedimento detalhado;
- regras de negócio;
- exceções;
- SLA;
- riscos e controles;
- evidências;
- KPIs;
- checklist;
- histórico de revisão e aprovação.

## Estrutura

- Financeiro
- Compras
- Recursos_Humanos
- Tecnologia
- Customer_Success
- Suporte
- Operacoes_TI
- Juridico
- _Templates_Gerais
